## What changed (live tree = `frontend/`, built by root `vite.config.js`)

- **Nav (`components/Nav.jsx`)** — the top bar is now slim: brand left, and at
  the **top right an animated sunflower** (hand-built SVG `SunflowerMark`:
  swaying stem + slowly spinning petal ring, CSS-only motion) labelled MENU.
  It opens a **slide-in pop-out drawer** whose background is the **live
  sunflower-field video** (`/sunflower-field-bg.mp4`) under a deep-brown
  scrim; links are Playfair Display cream with text-shadow (AA on the
  wallpaper). All 8 original links + Family Login/Sign-out behavior kept
  verbatim. Escape/backdrop close, focus moves in/out, body scroll locks,
  `prefers-reduced-motion` swaps video for the poster still and stops the
  animations.
- **Live scene wallpaper (`components/SunflowerBackdrop.jsx`)** — fixed
  full-screen sunflower video behind every public page (Home, Blog, Mental
  Health, Healthy Food, Kitchen, Shorts) under a warm cream scrim (88/76/88%)
  so text keeps AA contrast. The poster still paints first; the video fades
  in on browser idle so it never fights first paint. Private areas
  (Intro/Login/Family Zone/Warp/games) untouched.
- **Books toward the header (`components/BooksPromo.jsx`)** — "Paige's Books"
  now sits **directly under the hero** on Home: both books with covers
  (WebP + PNG fallback), titles, descriptions and the real Amazon links,
  carried verbatim from the site's original footer feature.
- **Playfair Display** — font link now loads 500–800 + italic; brand, drawer
  links, books headings and section titles use it (Tailwind `font-serif`).
- **Media diet** — the 3.0 MB opener clip stays for the Intro, but page
  backgrounds and the "Beautiful Moments" section now use a 359 KB
  recompressed derivative (same 752×416 picture, audio stripped) + a 45 KB
  poster frame. Book covers ship as 23 KB WebP (were 122 KB PNG).
- **Performance** — route-level `React.lazy` code splitting (initial JS per
  route ≈ 238 KB entry + ~7–15 KB route chunks instead of one 291 KB
  bundle); framer-motion removed from the nav path (131 KB chunk → 6.7 KB,
  animations are CSS now); Home/Nav chunks modulepreloaded; below-fold Home
  sections lazy; ambient emoji particles start after load/idle and never
  for reduced-motion visitors; sticky header dropped `backdrop-blur`;
  hero glow blobs are radial-gradients instead of `blur-3xl` filters.
- **Accessibility fixes** — music player button got an accessible name;
  low-contrast labels darkened (smile-challenge, "Updated weekly", hero
  "Floating quote", footer legal row). Lighthouse accessibility = **1.00**.

Untouched by design: Family Zone/auth logic, AdSenseGate, the Intro opener
flow, all family content and private areas.

## Deploy

`npm run deploy` from the repo root (build + `wrangler deploy`, Worker
`paigeswaincom`). **This sandbox has no Wrangler or GitHub credentials**
(`wrangler whoami` = not authenticated; git push = no username), so the
deploy must run from the authenticated bench (as the Oct 16 deploy did):
push/merge `paige-polish-2026-10-17`, run `npm run deploy`, then verify
https://paigeswain.com/home (new asset hashes) and re-run Lighthouse live.
